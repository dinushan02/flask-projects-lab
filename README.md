# Flask Projects Lab 🐍🌶️

A collection of Python Flask projects built while learning backend and full-stack web development — from beginner fundamentals to more advanced, real-world applications.

Each project lives in its own folder with its own `README.md`, `requirements.txt`, and setup instructions.

## 🎯 Purpose

This repo documents my journey learning **Flask**, a lightweight Python web framework. Every project focuses on a specific concept — routing, templates, databases, authentication, REST APIs, deployment — so I can build a strong foundation before moving to bigger applications.

## 🛠️ Tech Stack

- **Language:** Python 3.x
- **Framework:** Flask
- **Database:** SQLite / PostgreSQL (project-dependent)
- **ORM:** SQLAlchemy
- **Frontend:** HTML, CSS, Jinja2 (Bootstrap/Tailwind in later projects)
- **Other tools:** Flask-Login, Flask-WTF, Flask-RESTful, Flask-Migrate, JWT

## 🚀 Getting Started

Each project folder is self-contained. To run any project:

```bash
cd project-folder
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate
pip install -r requirements.txt
flask run
```
